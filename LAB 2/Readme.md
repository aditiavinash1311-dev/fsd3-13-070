## FS- file system (Node js's Module)
#### It directly connects with clients OS rather than browser

## Major task of FS module

- Reading and writing files
    - read file()
    - writefile()
    - appendfile()
- directory management
    - mkdir()
    - rmdir()
    - readdir()
    - rm()
- metadata/ Information
    - stat()
    - lstat()
    - fstat()

- watching for changes 
    - watch()
    - watchfile()
    - unwatchfile()
- Streaming Large file
    - createreadstream()
    - createwritestream()
- File operations
    - rename
    - truncate()
    - unlink
    - link
    - syslink()
